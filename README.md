# 一餐 · 外卖盲盒作品体验

静态交互作品：按预算、口味、餐品数量与热量限制体验随机开盒，包含液态玻璃效果和本次页面的开盒记录。

不提供账户注册、真实下单、支付或配送。餐品、价格、热量为示例数据，无需输入个人信息；刷新页面会清空体验记录。

此仓库仅发布前端构建产物，不含后端、数据库、用户信息或密钥。

## 发布
在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 /(root)。

预期访问地址：https://limmo666.github.io/limmo/

## 技术与素材
React + Vite + liquid-glass-react。组件 MIT 许可见 liquid-glass-react-LICENSE.txt。餐盒图片为 AI 生成的餐食示意。
